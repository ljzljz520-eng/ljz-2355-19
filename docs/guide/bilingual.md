# 双语对照阅读

文档中心提供中英双语对照阅读器，左右两栏按**语义节点**（而非段落序号）同步滚动。

## 启动

```bash
npm run docs:seed   # 从 docs/ 解析中英文 Markdown 建库（SQLite）
npm run docs:server # 启动内容 API + 阅读器 http://localhost:5174
```

## 能力一览

- **语义对齐**：中文一段可对应英文多段，对齐关系存于对齐表，不依赖数组下标
- **翻译基线**：每段译文记录基于哪版原文；原文修改后仅相关译段标记「待复核」，未改段保留「已验证」
- **共享代码**：代码块、参数名等不可翻译内容双语引用同一来源，译文不复制代码
- **语言锁 vs 对齐图**：整篇语言锁与段落级对齐图互相比对，过期译文不会被包装成「完全同步」
- **人工入口**：待复核确认、对齐冲突解决、整篇锁定均在阅读器内完成
- **历史版本**：搜索可命中历史版本，进入后明确标注非最新内容
