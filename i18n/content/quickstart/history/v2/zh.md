# 快速开始

<!-- i18n:id=intro -->
本节介绍如何在项目中使用 My Component Lib。

## 安装

<!-- i18n:id=install-desc -->
我们建议使用包管理器安装，也可以通过 CDN 引入。

<!-- i18n:id=install-code code=install-npm lang=bash -->
```bash
npm install my-component-lib
```

## 基础用法

<!-- i18n:id=usage-desc -->
在入口文件中调用 `createApp`，并注册 `MyComponentLib`；参数名 `options` 保持不变。
