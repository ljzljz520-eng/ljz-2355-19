# Quick Start

<!-- i18n:id=intro xref=intro -->
This section explains how to use My Component Lib in your project.

## Installation

<!-- i18n:id=install-desc xref=install-desc -->
We recommend installing via NPM.

<!-- i18n:id=install-code code=install-npm lang=bash -->
```bash
npm install my-component-lib
```

## Basic Usage

<!-- i18n:id=usage-desc xref=usage-desc -->
Call `createApp` in your entry file and register `MyComponentLib`.
